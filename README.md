# Z You App Store

Official public website repository for **Z You Software Solutions**.

## Launch apps
- Z You Mini Grocery POS — Windows + Android scanner
- Z You School Face Attendance — Windows + Android scanner

## Licensing
The main Windows products use a **7-day free trial** on first use. After the trial, customers activate a device-bound subscription for **1 Month** or **1 Year**. Companion Android scanners do not require a separate subscription.

## Security
Product source code remains in private repositories. The Owner Subscription Toolkit and private signing keys must never be committed to this public repository.

## Public downloads
Download buttons are enabled only after the exact verified installer/APK files have been published publicly.
